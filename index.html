Daftarkan tim kamu

Isi data tim di bawah. Panitia akan memeriksa pendaftaran sebelum tim masuk ke bracket.

Kategori
Pemain: 5 inti dan 1 cadangan

ID dan Server ada di profil MLBB, misalnya 123456789 (1234). Satu ID hanya boleh terdaftar di satu tim.

Alur pendaftaran

  1. Kirim formulir

    Isi data tim, 5 pemain inti, dan 1 cadangan jika ada.

  2. Tunggu persetujuan

    Cek hasilnya di halaman Status tim dengan nama tim kamu.

  3. Masuk bracket

    Setelah semua tim diperiksa, panitia mengundi posisi bracket.

Ketentuan singkat
  • Maksimal 16 tim untuk setiap kategori.
  • Nama tim dan ID pemain tidak boleh sama dengan tim lain.
  • Kategori Pelajar wajib mengisi asal sekolah.
  • Panitia menghubungi kapten lewat WhatsApp.
